7 question:Take a string from the input and check whether or not it contains both letters and numerals

Input(1):
R2D2
Output(1):
true
Input(2):
OC
solu: 
    s = input()

    has_letter = any(ch.isalpha() for ch in s)
    has_digit = any(ch.isdigit() for ch in s)

    if has_letter and has_digit:
      print("true")
    else:
      print("false")

18 question:Count the total vowels and consonants in a given string and print them

Input:
Harry Potter
Output:
3
9

solu:
     s = input()

     vowels = 0
     consonants = 0

     for ch in s.lower():
         if ch in "aeiou":
            vowels += 1
    elif ch.isalpha():
        consonants += 1

    print(vowels)
    print(consonants)
19 question:Check the given 2 strings are anagrams.

Hint: anagram means the strings contains same characters but order of characters is not important

Note: Ignore considering the case or spaces.

Input(1):
Listen
Silent
Output(1):
true
Input(1):
School master
The classroom
Output(1):
true

solu:
     s1 = input().lower().replace(" ","")
     s2 = input().lower().replace(" ","")
